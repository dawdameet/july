The Engine Pipeline
MacBook → Wi-Fi → Fedora Linux Box
STEP 01
In-Memory Packing
Dispatcher scans repo files and packs them into RAM in 2 ms. No tar/gzip overhead.
STEP 02
Raw Binary Socket
Memory-aligned 0x4A554C59 frame + JSON manifest streamed over persistent TCP.
STEP 03
Kernel Sandboxing
Worker isolates with CLONE_NEWUSER, CLONE_NEWNET (offline loopback) & RLIMIT_DATA.
STEP 04
tmpfs Compilation
Worker executes GCC directly in RAM disk; zero NVMe disk thrashing.
STEP 05
Zero-Copy DMA Return
Compiled binaries streamed back via Linux sendfile() directly from page cache.
