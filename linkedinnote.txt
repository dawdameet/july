update on July (distributed C execution engine across LAN).

the devlog was getting too long, so here’s the tl;dr in Q&A:

what is it?
> turns any spare linux box on your LAN into ambient compute in milliseconds.

how fast?
> shipped a full C repo over Wi-Fi, compiled with gcc -O3, ran 4 threads, and downloaded the binary back in 580 ms total (orchestration overhead: ~80 ms).

why not docker / ssh?
> no container daemon, no layer caching delays, no ssh negotiation. 
> packs files in RAM in 2 ms, sends raw memory-aligned envelope (0x4A554C59 header), unpacks straight into tmpfs (RAM disk).

auth?
> 0-RTT header check (X-July-Token). no token = instant 401 Unauthorized. neighbors can't mine crypto.

security?
> linux kernel namespaces (CLONE_NEWUSER, CLONE_NEWNS, CLONE_NEWPID, CLONE_NEWNET).
> offline loopback mode by default (builds cannot phone home or scan LAN) + memory ceiling via RLIMIT_DATA.

how tcp session not adding ms?
> interactive ambient console (`july>`) holds a single warm TCP connection pool.
> fire tasks with zero handshake delay. close laptop lid = clean disconnect.

numbers on warm vs cold tcp?
> warm tcp: 1,929 req/s | avg 9.5 ms | p99 21.6 ms
> cold tcp:  833 req/s  | avg 23.8 ms | p99 304.7 ms
> 2.32x faster throughput, 60% lower latency, 14x lower p99 tail (avoids TCP SYN overhead & TIME_WAIT socket exhaustion).
> sustained 2,762 req/s with keep-alive under stress.

downloading compiled artifacts?
> zero user-space copying. linux kernel `sendfile()` streams page cache straight into socket TX buffers via DMA.

concurrency?
> fired 5 distinct workloads in parallel (matrix multiplication, 16-shard KV store with 1.7M ops/sec, financial ticker pipeline, telemetry, sandbox tests).
> compiled 3 GCC builds simultaneously and streamed ~8.5 MB back in 3.2 seconds.
