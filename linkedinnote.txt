July: distributed C execution engine across LAN.

devlog in Q&A:

what is it?
> turns any spare linux box on your LAN into ambient compute in milliseconds.

how fast?
> shipped a C repo over Wi-Fi, compiled with gcc -O3, ran 4 threads, got the binary back in 580 ms.
> breakdown: 2 ms pack, 3 ms transfer, 3 ms tmpfs unpack, 420 ms gcc, 51 ms run, 10 ms sendfile() DMA (orchestration: ~80 ms).

why not docker / ssh?
> no daemon, no layer cache lag, no 300-800 ms ssh handshake.
> packs in RAM in 2 ms, sends raw memory-aligned envelope (0x4A554C59 header), unpacks into tmpfs.

auth?
> 0-RTT header check (X-July-Token). no token = instant 401. neighbors can't mine crypto.

security?
> linux kernel namespaces (CLONE_NEWUSER, CLONE_NEWNS, CLONE_NEWPID, CLONE_NEWNET loopback-only). builds can't phone home or scan LAN + RLIMIT_DATA memory cap.

how tcp session not adding ms?
> ambient console (`july>`) keeps a warm TCP pipe open. 0 ms handshake delay. close laptop lid = clean exit.

warm vs cold tcp shootout?
> 2,000 requests over Wi-Fi (20 threads):
> • throughput: 1,929 vs 833 req/s (2.32x faster)
> • avg latency: 9.54 vs 23.81 ms (60% lower)
> • p50: 8.89 vs 18.90 ms | p95: 14.91 vs 34.57 ms
> • p99 tail: 21.65 vs 304.71 ms (14x better)
> cold conns get trashed by TCP SYN queues & TIME_WAIT socket churn.

sustained stress test?
> 50 concurrent connections over 10s:
> • 27,618 requests in 10s (2,762 req/s sustained, 4,045 peak)
> • 100% 202 Accepted, 0 errors, 0 dropped sockets.

downloading artifacts?
> zero-copy DMA. linux kernel `sendfile()` streams page cache straight to socket TX buffers.

concurrency under load?
> fired 5 workloads in parallel (make -j5):
> • 16-shard KV store: 100k txns to binary WAL @ 1.72M ops/s
> • 512x512 matrix multiply: 7.62 GFLOPS
> • C ticks + Python 3 analytics: 1.27M ticks/s (7.25 MB stream)
> • multithreaded prime telemetry + kernel sandbox test
> pegged all cores to 100%, 3 GCC builds in tmpfs, streamed ~8.5 MB back in 3.2s.

what it means for you?
> laptop stays cool and silent. zero fan noise or battery drain from builds and test suites.
> code on macOS ARM64, compile & test native x86_64 Linux in <600 ms without heavy VMs.
> no SSH keys, no rsync lag, no Dockerfiles. the idle box in the corner is an ambient extension of your terminal.

specs (for reproducibility):
> client: Apple M1 MacBook Air (8 GB, macOS)
> worker: Intel i3-1005G1 (2C/4T @ 1.2GHz), Fedora 40 (x86_64, Linux 6.8+), tmpfs
> network: consumer home Wi-Fi (~2-3 ms ping)
> compiler: gcc 14 (-O3 -pthread -mavx2)
